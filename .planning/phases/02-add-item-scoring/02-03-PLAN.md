## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Клиент (форма) → Server Action | Недоверенный payload формы пересекает границу; сервер обязан ре-валидировать и брать userId из сессии |
| Неаутентифицированный вызов → Server Action | Server Action может быть вызван без сессии |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-2-01 | Tampering / Elevation | `createItem` (mass-assignment) | high | mitigate | `userId` только из `requireUser()`; в write идут только `parsed.data`; total/id клиент не задаёт |
| T-2-03 | Spoofing | неаутентифицированный вызов `createItem` | high | mitigate | `requireUser()` бросает до любой записи при отсутствии сессии |
| T-2-04 | Tampering | серверная ре-валидация входа | high | mitigate | `itemInputSchema.safeParse(input)` в Server Action (never-trust-client V5), несмотря на клиентский RHF |
| T-2-05 | Tampering (XSS) | рендер title в карточке / переход по ссылке | medium | mitigate | React экранирует по умолчанию; ссылка (план 04) валидируется z.url; без dangerouslySetInnerHTML |
| T-2-SC | Tampering | `npx shadcn add` | medium | accept | Только официальный реестр shadcn (components.json registries пуст); copy-in код, не npm-пакет — vetting неприменим |
</threat_model>
