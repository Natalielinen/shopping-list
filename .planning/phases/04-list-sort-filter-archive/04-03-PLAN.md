## Phase Goal (MVP-срез)

**Как** авторизованный пользователь, **я хочу** видеть свои покупки mobile-first списком, отсортированным по приоритету, переключать сортировку и фильтры и отмечать покупки купленными (с уходом в архив), **чтобы** понимать, что покупать в первую очередь, и держать активный список чистым.

> История выведена дословно из ROADMAP `**Goal:**` Фазы 4 + Core Value.

**Срез плана 04-03 (TRACER):** тончайший сквозной путь «отметить одну покупку купленной» — чекбокс на карточке → Server Action, scoped по `userId` → repo-шов (04-01) → `router.refresh()` → покупка исчезает из активного списка + undo-тост. Один путь через ВСЕ слои фазы (RSC-примитивы → клиентский `ListView` → client-leaf с оптимистикой → Server Action → repo → PG), доказанный сквозным Playwright-тестом. Панель сортировки/фильтра и секция «Куплено» — расширение (план 04-04).
