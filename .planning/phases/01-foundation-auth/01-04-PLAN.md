<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| login error surface → user | Сообщение об ошибке не должно раскрывать существование аккаунта |
| authenticated session → logout | Выход обязан инвалидировать серверную сессию, а не только UI |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-ENUM | Information Disclosure | Ошибка входа | high | mitigate | Обобщённое «Неверный email или пароль» через `mapAuthError`; логин не различает несуществующий аккаунт и неверный пароль (V7, prohibition) |
| T-04-LOGOUT | Spoofing | Инвалидация сессии | high | mitigate | `authClient.signOut()` очищает серверную DB-сессию и cookie; e2e подтверждает, что после выхода `/list` редиректит на `/login` (V3, D-09) |
| T-04-IDOR-E2E | Elevation of Privilege | Список за авторизацией | high | mitigate | Браузерный тест изоляции: B не видит данные A; дополняет интеграционный якорь плана 02 (V4, AUTH-04) |
| T-04-ERRLEAK | Information Disclosure | Server error → UI | medium | mitigate | Сетевые/серверные ошибки маплятся на общий текст; verbose-детали БД не доходят до клиента (V7) |
</threat_model>
