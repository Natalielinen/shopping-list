<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser form → authClient → Better Auth | Учётные данные пересекают клиент-серверную границу |
| protected route → server guard | Доступ к `/list` разрешён только при валидной серверной сессии |
| RSC page → client leaf | Секреты не должны попасть в клиентский бандл через `'use client'` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-SESSION | Spoofing | Сессия / httpOnly cookie | high | mitigate | Серверный `getSession()` guard в `(app)/layout.tsx` — граница безопасности (не middleware/proxy); cookie httpOnly через `nextCookies` (Pattern 3, V3) |
| T-03-SECRETLEAK | Information Disclosure | Клиентский бандл | high | mitigate | Страницы/layout остаются RSC; интерактивность в leaf `'use client'`; `server-only` на auth/db модулях; секреты unprefixed (Pitfall 4, V6) |
| T-03-CSRF | Tampering | Auth-эндпоинты | medium | mitigate | Встроенная CSRF/cookie-защита Better Auth; same-origin `authClient` (V-CSRF) |
| T-03-OPTIMISTIC | Elevation of Privilege | Защита маршрутов | medium | mitigate | Не полагаться на оптимистичную проверку cookie в proxy/middleware; реальная валидация только на сервере (Pattern 3 trade-off) |
</threat_model>
