## Выбор зависимости (ITEM-06)

| Option | Description | Selected |
|--------|-------------|----------|
| Одна, через Select | Nullable self-FK `depends_on` → items.id; shadcn Select из своих покупок (без самой себя); MVP-просто, совпадает со стеком | ✓ |
| Несколько | Join-таблица + multi-select; гибче, но сложнее (агрегация «все ли куплены», больше краевых случаев) | |

**User's choice:** Одна, через Select

## Механика блокировки (DEP-01)

| Option | Description | Selected |
|--------|-------------|----------|
| Прямая, на чтении | Заблокирована ⇔ `depends_on` не null И у зависимости `purchasedAt` null; авто-разблокировка; серверный guard + disabled-чекбокс; без рекурсии | ✓ |
| Транзитивная цепочка | A→B→C: A заблокирована, пока не куплена вся цепочка; реалистичнее, но нужен обход графа | |

**User's choice:** Прямая, на чтении

---

## Визуал заблокированной (DEP-02)

| Option | Description | Selected |
|--------|-------------|----------|
| Замок + подпись | Иконка «замок» + disabled-чекбокс + подпись «Заблокировано: {название}»; избыточный канал, понятно почему и от чего | ✓ |
| Замок + tooltip | Замок + disabled-чекбокс; название зависимости в tooltip; компактно, но причина скрыта до наведения (хуже на mobile) | |
| Только приглушение | Приглушённая карточка + disabled-чекбокс; минималистично, но непонятно почему | |

**User's choice:** Замок + подпись

---

## Целостность зависимостей

| Option | Description | Selected |
|--------|-------------|----------|
| Запретить циклы + FK null | Запрет циклов при выборе (самоссылка + по цепочке); при удалении зависимости `depends_on` → null (без каскада) | ✓ |
| Только самоссылка | Запретить только A→A; длинные циклы не проверять — проще, но A→B, B→A залипнут заблокированными навсегда | |

**User's choice:** Запретить циклы + FK null. Follow-up: реализация `depends_on → null` — **FK `onDelete: "set null"`** (БД-enforced, а не ручная чистка в коде).

## Claude's Discretion
