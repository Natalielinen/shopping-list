## Phase Goal (MVP-срез)

**Как** авторизованный пользователь, **я хочу** выбрать в форме другую свою покупку как зависимость и видеть зависимую покупку заблокированной (иконка-замок, подпись «Заблокировано: …», недоступный чекбокс), пока зависимость не куплена, **чтобы** покупать вещи в правильном порядке и понимать, почему что-то пока нельзя отметить.

> История выведена дословно из ROADMAP `**Goal:**` Фазы 5 + success criteria SC-1…SC-3.

**Срез плана 05-03 (TRACER):** тончайший сквозной путь фазы, прошитый через ВСЕ слои поверх уже мигрированной схемы (план 05-02) и чистого ядра (план 05-01): выбрать свою покупку зависимостью в форме → Server Action (владение + цикл) → persist `depends_on` → список выводит производный `blocked`/`dependencyTitle` примитивами → `ItemCard` рисует строку `Lock` + `disabled`-чекбокс → покупка зависимости → `router.refresh()` → авто-разблокировка. Доказан сквозным Playwright-тестом (happy path + путь ошибки цикла). Серверный guard «куплено» (D-03, defense-in-depth) — расширение (план 05-04).

<objective>
Прошить архитектуру зависимости и блокировки насквозь на одном пути:
1. Форма и действия (задача 1): `createItem`/`updateItem` принимают `dependsOn`, проверяют владение (`candidate ∈ findItemsForUser`) и цикл (`wouldCreateCycle`), возвращают `{ ok:false, error, field?: "dependsOn" }`; RSC-обёртки `new`/`edit` строят кандидатов и (для edit) prefill; `AddItemForm` получает `Select` зависимости + проп `candidates` + ошибку цикла под полем.
2. Список и блокировка (задача 2): `list/page.tsx` выводит `blocked`/`dependencyTitle` из загруженного набора примитивами; `sort.ts`/`ListView`/`ItemCard` пробрасывают их; `ItemCard` рисует строку `Lock`; `PurchaseCheckbox` при `blocked` — `disabled`. Сквозной e2e доказывает happy path + путь ошибки цикла.

Purpose (почему tracer): самый большой архитектурный риск — граница RSC→client для производного `blocked` (только примитивы, §Pitfall 4) и авто-разблокировка на существующем `router.refresh()`. Прошиваем один путь на лучших ранних токенах, чтобы поймать тупик после одного коммита. Владение/цикл включены сразу — это security-критичный шов (never-trust-client), а не «позже».
Output: рабочий выбор зависимости + видимая блокировка + авто-разблокировка end-to-end, доказанные e2e.
</objective>
