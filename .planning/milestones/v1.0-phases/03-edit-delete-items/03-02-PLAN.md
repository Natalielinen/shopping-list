<user_story>
**Как** авторизованный пользователь, **я хочу** удалить свою покупку с явным подтверждением, **чтобы** убирать из списка ненужное, не боясь случайного необратимого действия.

*(Выведено дословно из ROADMAP §"Phase 3" Goal + Success Criterion №2 — не изобретено.)*
</user_story>

<objective>
Расширение проверенного edit-слайса (Plan 01) на удаление покупки (ITEM-08). Delete — самостоятельный тонкий слайс поверх той же архитектуры: иконка «корзина» на карточке → AlertDialog подтверждение → Server Action deleteItem (userId из сессии, scoping) → router.refresh(), покупка исчезает. Жёсткое удаление, без undo/архива (архив — Фаза 4).

Зависит от Plan 01: делит файлы `items.ts`, `items.iso.test.ts`, `edit/actions.ts`, `edit/actions.test.ts`, `ItemCard.tsx` (edit-слайс уже добавил в них find/update, updateItem и иконку Pencil) → Wave 2.

Purpose: Дать пользователю удаление своих покупок с защитой от случайного необратимого действия (D-05) и изоляцией по userId (D-06/D-09, SC-3).
Output: shadcn AlertDialog, repo deleteItemForUser, Server Action deleteItem, компонент DeleteItemButton, delete-иконка в ряду действий ItemCard, e2e delete-item.spec.ts.

Обратимость: решения delete (D-05/D-06) — reversible (код/компонент); само удаление для пользователя необратимо в этой фазе (нет восстановления) — поэтому обязательное модальное подтверждение, а не тихое удаление.
</objective>
