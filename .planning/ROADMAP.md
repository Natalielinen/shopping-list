# Roadmap: Shopping List с приоритетами

## Overview

Путь от пустого репозитория до работающего мультипользовательского списка покупок с автоматическим приоритетом. **Milestone v1.0 (MVP) завершён** — аутентификация с изоляцией данных по пользователю, добавление покупок с автоматическим приоритетом и разбивкой очков, редактирование/удаление, mobile-first список (сортировки, фильтры, архив) и зависимости с блокировкой.
